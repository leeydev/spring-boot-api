# Spring Boot API

Enterprise-grade REST API built with Spring Boot 3 and JPA.

## Features

- 🍃 Spring Boot 3
- 💾 JPA/Hibernate
- 🧪 Unit & Integration tests
- 📝 REST endpoints
- 🏗️ Layered architecture

## Build

```bash
mvn clean install
mvn spring-boot:run
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/products | List products |
| POST | /api/products | Create product |

## Testing

```bash
mvn test
```
